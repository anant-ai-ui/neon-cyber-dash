# 🏃‍♂️ Neon Cyber Dash - Web Edition

A fast-paced, responsive 2D endless runner web game built purely with HTML5 Canvas, CSS3, and Vanilla JavaScript. Originally developed in Python (Pygame) and ported to the web for seamless mobile and desktop gameplay.

## ✨ Features

* **🤖 Dual Game Modes (NEW):** Choose between playing the game yourself or activating the **AI Auto-Pilot**! Watch a custom heuristic algorithm mathematically calculate distances and dodge obstacles in real-time.
* **Touch & Swipe Controls:** Fully optimized for mobile devices (Swipe Up to Jump, Swipe Down to Duck).
* **Real-time Synth Sounds:** Custom audio generated on-the-fly using the Web Audio API (No external sound files!).
* **In-Game Shop:** Collect coins to unlock and equip new player shapes, colors, and a coin magnet.
* **Local Leaderboard:** Automatically saves and displays the Top 5 high scores directly in the browser.
* **Procedural Parallax Background:** Dynamic neon cyber particles and shifting themes based on your score progression.
* **Secret Dev Mode & AI Controls:** Includes a hidden swipe sequence to unlock developer controls, plus live speed-manipulation buttons while watching the AI play!

## 🎮 How to Play

1. Enter your name on the prompt screen to start.
2. Select **PLAY YOURSELF** to take control, or **WATCH AI PLAY** to see the bot in action.
3. **Swipe UP** (or Drag Up) to jump over ground obstacles.
4. **Swipe DOWN** (or Drag Down) to duck under flying obstacles.
5. Collect gold coins to buy upgrades in the Shop.
6. Avoid red and yellow obstacles to survive!

## 🛠️ Technologies Used

* HTML5 (Canvas API)
* Vanilla JavaScript (ES6)
* Web Audio API
* CSS3
